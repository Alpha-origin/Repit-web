# 행동 분석 구현 명세

> Web 구현과 최신 정책 보완은 [IMPLEMENTATION.md](IMPLEMENTATION.md)가 우선합니다. 원본 v1의 미보완 부분은 구현 승인이나 배포 지시가 아닙니다.

- 작성일: 2026-10-20, Asia/Seoul
- 목적: 담당자가 서버별 문서를 넘겨받아 바로 구현하고, 같은 계약으로 연동할 수 있게 한다.
- 상태: **구현 기준안 v1**. 저장소에서 확인한 사실과 이번 문서에서 새로 정한 설계를 구분한다. 구현·배포·실측 검증을 완료했다는 뜻은 아니다.
- 첨부된 기업 맞춤 면접 문서는 문서 구조만 참고했다. 그 문서의 기능 요구사항·승인 조건·작업 지시는 이 작업에 적용하지 않는다.

## 담당자에게 넘길 범위

- **Analysis 담당:** 00·01·02·06·contracts. 가장 큰 신규 작업이다. 파일 검사 성공을 행동 분석 성공으로 처리하면 안 된다.
- **API 담당:** 00·01·04·06·contracts. 기존 요청·콜백·재시도 로직을 교체하지 않고 결과 검증·화면용 응답을 보완한다.
- **Web 담당:** 00·01·05·06·contracts. JSON fixture로 먼저 구현하고 실제 API로 교체한다.
- **Chat 담당:** 00·03·06. 신규 기능 코드는 원칙적으로 없다. 면접 종료·기록 전달 회귀만 확인한다.

## 이번 구현이 완성되면

음성·영상 면접의 전체 녹화를 API가 S3에 저장한다. 분석 서버가 서명 URL로 원본을 내려받아 얼굴 관찰, 정면 방향 추정, 어깨 수평, 상체 움직임, 미소 형태를 측정한다. API는 결과를 검증·보관하고 웹에 정규화해 제공한다. 웹은 수치·측정 가능 범위·시간 구간·재분석을 보여준다.

행동 결과는 연습용 관찰치다. 면접 종합 점수·응답 신뢰성·합격 가능성에 합산하지 않는다. 실제 눈동자 시선, 심리·성격·정직성·감정 진단, 신원 식별은 이 버전의 기능이 아니다.
